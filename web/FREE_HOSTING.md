# Free hosting & preview

This project is designed so you can preview locally and publish the frontend for free. The backend requires a host that can run Node.js; several providers offer free starter tiers but check current availability.

Quick publish choices (free):
- Frontend: Vercel or Netlify (deploy from GitHub) or GitHub Pages (static)
- Backend: Railway or Render (check current free tier availability). Another option is to run the backend on a small VPS or in a free student cloud account.

If you'd like, I can add a GitHub Actions workflow to build and deploy the frontend automatically to GitHub Pages. Reply if you want that added.
