# Web (Vite + React)

The frontend runs on port 5173. It includes:
- Landing page with MVFX branding
- Register / Login
- Demo and Live account selector
- Chart view for BTC, ETH, XAUUSD, EURUSD with selectable timeframes
- Trade ticket for buy/sell with SL/TP
- Dashboard showing demo account balance, positions and history
- AI assistant widget with text-to-speech

Run:
  cd web
  npm install
  npm run dev
