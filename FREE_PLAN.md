# Free plan notice

This MVFX repository is implemented using only free public services and libraries by default. The following free features are used:

- Binance public REST & WebSocket streams for cryptocurrency klines and orderbook (no API key required).
- Alpha Vantage (optional) for forex/XAU intraday klines — free tier available but limited rate; set ALPHA_VANTAGE_KEY to enable.
- Open-source libraries: React, Vite, Express, Socket.IO, lightweight-charts.
- SQLite for local demo database.

I will continue enhancements under the free plan: no paid third-party services will be added unless you request them.
